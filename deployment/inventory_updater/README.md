# Установка обновлятора движения товара

Требуется Windows 10/11 и обычный Python 3.12 с включённым Python Launcher.

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Запустите `install_inventory_updater.cmd`.
3. Введите логин и пароль CRM. Пароль сохраняется только в защищённом хранилище Windows.
4. После завершения используйте ярлык **«Обновить движение товара»** на рабочем столе.

Установщик создаёт книгу в папке `Документы\Мокрый нос`, разворачивает приложение в
`%LOCALAPPDATA%\MokryiNosInventory`, устанавливает отдельное окружение и Chromium.
